# Student Money Copilot

**A student-focused financial assistant powered by QVAC Local AI and RGB on Bitcoin.**

Developed for the **RGB Hackathon | October 17–18, 2026**

## About the Project

Student Money Copilot simplifies everyday financial management by combining budgeting, spending insights, and RGB wallet functionality in a single application.

Students can ask financial questions in natural language, track upcoming expenses, evaluate purchase affordability, and interact with their RGB wallet through a user-friendly interface.

The application combines **Python-verified financial calculations, local AI explanations, and RGB payment functionality.**

## Key Features

### QVAC Local AI Copilot
- Qwen3 4B running locally.
- Natural-language financial assistance and tool calling.
- Budget explanations, spending insights, and affordability recommendations.

### RGB Wallet & Payments
- Integration with local RGB Lightning Node wallets.
- STUSD (Student Dollar) RGB asset support.
- RGB wallet balance retrieval.
- RGB invoice creation and asset transfers.
- Payment interaction through the Streamlit interface.

### Student Budget Management
- Current balance and mandatory expense tracking.
- Flexible budget and purchase affordability calculations.
- Recurring expenses and transaction history.
- Spending summaries and category statistics.

### Streamlit Dashboard
- Financial dashboard.
- Money Copilot chat.
- Regular expenses.
- Transaction history.
- RGB wallet and payment interface.

## How It Works

Financial calculations are handled by Python rather than generated by the language model. QVAC provides natural-language explanations and recommendations based on calculated results.

The application follows this architecture:

```text
Python calculates
        ↓
QVAC explains
        ↓
User approves
        ↓
RGB executes
```

This separates deterministic financial calculations, AI-generated assistance, and wallet operations.

## RGB Integration Summary

During the hackathon, we extended the original mock RGB setup into a working local RGB payment flow using two RGB Lightning Node wallets:

- `studentcopilot` — sender
- `landlord2` — receiver

Both wallets were funded with test Bitcoin and prepared with RGB-capable UTXOs. We also issued an RGB NIA asset named **STUSD (Student Dollar)** for demonstration purposes.

### RGB Payment Flow

```text
Student wallet (studentcopilot)
        ↓
Create landlord blind RGB invoice
        ↓
Receive recipient ID
        ↓
Send STUSD via /sendrgb
        ↓
Transfer RGB consignment
through Iris JSON-RPC proxy
        ↓
Landlord wallet (landlord2)
receives STUSD assignment
```

This local demonstration illustrates an RGB asset payment between a student and a landlord. The STUSD asset is a demonstration token, not an actual fiat-backed stablecoin.

## Hackathon Development & Transparency

### Before the Hackathon

We prepared the initial project concept, repository, TypeScript agent scaffold, QVAC SDK setup, and mock RGB wallet tools.

The original mock agent passed **6/6 simulated evaluation scenarios**, without real-network asset transfers.

### During the Hackathon — October 17–18, 2026

We extended the initial agent into a student-focused financial application with local RGB payment capabilities.

- Developed the Streamlit dashboard, Money Copilot chat, and expense management interface.
- Implemented Python-based budgeting, spending insights, and affordability calculations.
- Integrated QVAC Qwen3 4B with financial tool calling.
- Connected RGB wallet information to the AI copilot.
- Set up two RGB Lightning Node wallets and funded them with test Bitcoin.
- Created RGB-capable UTXOs and issued the STUSD NIA demo asset.
- Implemented the local STUSD payment flow using blind invoices, `/sendrgb`, and the Iris JSON-RPC proxy.
- Separated demo EUR budgeting data from RGB wallet information.

**Transparency:** The project builds upon pre-hackathon preparation and existing scaffolding. Earlier work and hackathon contributions are distinguished, and the original development history is preserved.

## Getting Started

```bash
git clone https://github.com/sudegkc/student-money-copilot.git
cd student-money-copilot

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

streamlit run app.py
```

Local QVAC model files and RGB Lightning Node wallet configuration must be set up separately.
